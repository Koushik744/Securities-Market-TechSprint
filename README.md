# Securities Market TechSprint

AI-powered investment platform built for the Securities Market TechSprint.

## Repository structure

```
Securities-Market-TechSprint/
└── investone-ai/   # Next.js frontend
```

Additional services (backend, etc.) will live as sibling directories alongside `investone-ai/`.

## Quick start

```bash
cd investone-ai
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

See [`investone-ai/README.md`](./investone-ai/README.md) for full setup details.
